# Code of Conduct / Código de Conduta

## Our promise / A nossa promessa

Lifesaver-ai is a welcoming project for everyone, in every country and language. We promise to keep it free of harassment and discrimination.

O Lifesaver-ai é um projeto acolhedor para todos, em todos os países e línguas. Prometemos mantê-lo livre de assédio e discriminação.

## Expected behaviour / Comportamento esperado

- Be respectful and kind
- Accept feedback with an open mind
- Focus on what helps users stay safe
- Respect privacy: never share other people's personal data

## Unacceptable behaviour / Comportamento inaceitável

- Insults, threats, harassment or discrimination
- Sharing private information without permission
- Using this project to harm, scam or deceive people
- Spam or deliberately misleading contributions

## Enforcement / Aplicação

Maintainers may edit or remove contributions, and may block people who break these rules.

Os responsáveis podem editar ou remover contribuições e bloquear quem quebrar estas regras.

## Reporting / Reportar

To report a problem with someone's behaviour, use the Security tab of this repository or open an issue without personal data.

Para reportar um problema de comportamento, usa o separador Security deste repositório ou abre uma issue sem dados pessoais.
