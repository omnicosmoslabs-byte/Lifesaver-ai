# Contributing / Contribuir

Thank you for helping make Lifesaver-ai safer and more useful.

Obrigado por ajudares a tornar o Lifesaver-ai mais seguro e mais útil.

## Ways to help / Formas de ajudar

- Report problems or ideas by opening an issue
- Improve a skill or a document
- Translate or fix wording in English or Portuguese
- Test the skills with real and tricky examples

## Before you send a change / Antes de enviar uma alteração

1. Read SECURITY.md and security/SECURITY_CHECKLIST.md.
2. Never include passwords, personal data or private documents.
3. Keep texts clear and simple, in English and Portuguese when possible.
4. Describe what you changed and why.

## Rules / Regras

- Be respectful. See CODE_OF_CONDUCT.md.
- Security problems go through the Security tab, never a public issue.
- By contributing, you agree that your work is shared under the Apache License 2.0.
