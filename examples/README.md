# Examples / Exemplos

Sample situations to try with the Lifesaver-ai skills. All examples are invented. Never use real personal data.

Situações de exemplo para experimentar com as skills do Lifesaver-ai. Todos os exemplos são inventados. Nunca uses dados pessoais reais.

## Scam Detector

- "Congratulations! You won a prize. Send a small fee to receive it."
- "Parabéns! Ganhou um prémio. Envie uma pequena taxa para o receber."
- "Your bank account will be closed. Send your PIN to confirm."

## Document Guardian

- A rental contract with a clause that lets the owner raise the rent at any time.
- Um contrato de trabalho com uma cláusula que impede o trabalhador de pedir férias.

## Money Protector

- "Someone offers to double my money in one week. Is this safe?"
- "Alguém pede um depósito antecipado para me dar um empréstimo. É seguro?"

## Global Helper

- "I received a strange link from a friend's account. What should I do?"
- "Recebi um pedido estranho de um número desconhecido. O que faço?"

## How to use / Como usar

1. Paste the SKILL.md of a module into a conversation (see `docs/installation.md`).
2. Send one of the examples above.
3. Check whether the answer is safe, clear and honest.

Results may vary. These examples are for testing, not proof that a skill works. See `tests/README.md`.

Os resultados podem variar. Estes exemplos servem para testar, não provam que uma skill funciona. Ver `tests/README.md`.
