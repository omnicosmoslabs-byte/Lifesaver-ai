# Security / Segurança

## Reporting a vulnerability / Reportar uma vulnerabilidade

If you find a security problem, please do not open a public issue.

Use the "Report a vulnerability" option in the Security tab of this repository.

Se encontrares um problema de segurança, não abras uma issue pública.

Usa a opção "Report a vulnerability" no separador Security deste repositório.

## What to include / O que incluir

- What you found and where
- Steps to reproduce it
- Why you think it is a risk

Never include real passwords, personal data or private documents in a report.

Nunca incluas palavras-passe reais, dados pessoais ou documentos privados num relatório.
