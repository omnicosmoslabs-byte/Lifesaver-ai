# Incident Response / Resposta a Incidentes

What we do when a security problem is found.

O que fazemos quando é encontrado um problema de segurança.

## Steps / Passos

1. **Receive**: a report arrives through the Security tab or a maintainer finds a problem.
2. **Assess**: decide how serious it is (low, medium, high, critical).
3. **Contain**: remove or fix the affected file or skill as fast as possible.
4. **Fix**: correct the cause, not only the symptom.
5. **Inform**: add a note to CHANGELOG.md explaining what happened and what changed.
6. **Learn**: update THREAT_MODEL.md and SECURITY_CHECKLIST.md if needed.

1. **Receber**: chega um relatório pelo separador Security ou um responsável encontra um problema.
2. **Avaliar**: decidir a gravidade (baixa, média, alta, crítica).
3. **Conter**: remover ou corrigir o ficheiro ou skill afetado o mais depressa possível.
4. **Corrigir**: resolver a causa, não só o sintoma.
5. **Informar**: acrescentar uma nota ao CHANGELOG.md a explicar o que aconteceu e o que mudou.
6. **Aprender**: atualizar THREAT_MODEL.md e SECURITY_CHECKLIST.md se necessário.

## If personal data is exposed / Se dados pessoais forem expostos

Remove the data immediately, tell the people affected as soon as possible, and explain how to protect themselves.

Remover os dados imediatamente, avisar as pessoas afetadas o mais depressa possível e explicar como se protegerem.

## Contact / Contacto

Use "Report a vulnerability" in the Security tab of this repository.

Usa "Report a vulnerability" no separador Security deste repositório.
