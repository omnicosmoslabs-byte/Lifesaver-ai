# Privacy Policy / Política de Privacidade

## Principles / Princípios

1. Privacy by default: we collect the minimum, or nothing.
2. We never ask for passwords, PINs, card numbers or identity document numbers.
3. We never sell personal data.
4. Users decide what to share, and can stop at any time.

1. Privacidade por defeito: recolhemos o mínimo, ou nada.
2. Nunca pedimos palavras-passe, PINs, números de cartão ou números de documentos de identificação.
3. Nunca vendemos dados pessoais.
4. Os utilizadores decidem o que partilham e podem parar a qualquer momento.

## This repository / Este repositório

This repository contains only open-source skill files and documents. It does not collect user data.

Este repositório contém apenas ficheiros de skills e documentos open source. Não recolhe dados dos utilizadores.

## Future services / Serviços futuros

If we add an API, website or cloud service, we will update this policy before launch and explain clearly what data is used and why.

Se adicionarmos uma API, um website ou um serviço na nuvem, atualizamos esta política antes do lançamento e explicamos com clareza que dados são usados e porquê.

## Contact / Contacto

Questions about privacy: use the Security tab or open an issue without personal data.

Dúvidas sobre privacidade: usa o separador Security ou abre uma issue sem dados pessoais.
