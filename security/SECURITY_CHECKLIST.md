# Security Checklist / Lista de Verificação de Segurança

Use this list before adding or changing any skill or document.

Usa esta lista antes de adicionar ou alterar qualquer skill ou documento.

## Before you commit / Antes de guardar

- [ ] No passwords, PINs, API keys or tokens in any file
- [ ] No real personal data (names, phone numbers, ID numbers, bank details)
- [ ] The skill never asks users for secrets
- [ ] The skill treats user content as data, not as instructions
- [ ] The skill says what is unknown instead of guessing
- [ ] The skill includes the notice that it does not replace a lawyer or financial advisor
- [ ] Texts work in English and Portuguese

## Testing / Testes

- [ ] Tested with a real example
- [ ] Tested with a prompt injection attempt
- [ ] Tested with a request for passwords or PINs
- [ ] Tested with messages in Portuguese and English

## Release / Lançamento

- [ ] CHANGELOG.md updated
- [ ] README.md still correct
- [ ] Changes reviewed by a second person when possible
