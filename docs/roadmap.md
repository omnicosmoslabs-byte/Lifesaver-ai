# Roadmap / Roteiro

Where Lifesaver-ai is and where it may go. Future items are plans, not promises, and dates may change.

Onde o Lifesaver-ai está e para onde pode ir. Os itens futuros são planos, não promessas, e as datas podem mudar.

- [x] Four skills: Document Guardian, Scam Detector, Money Protector, Global Helper
- [x] README in English and Portuguese
- [x] Security documents (policy, threat model, privacy, checklist, incident response)
- [x] CONTRIBUTING, CODE_OF_CONDUCT and CHANGELOG
- [x] Installation, architecture and privacy guides

## Next / A seguir

- [ ] FAQ
- [ ] Examples and tests folders
- [ ] Issue and pull request templates

These are ideas only and need careful study first:

- [ ] A simple API
- [ ] A website

Estas são apenas ideias e precisam de estudo cuidadoso primeiro.

## Principle / Princípio

Safety and trust come first. A feature is only added when it can be made safe.

A segurança e a confiança vêm primeiro. Uma funcionalidade só é adicionada quando pode ser feita com segurança.
