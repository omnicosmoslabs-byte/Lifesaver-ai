# FAQ / Perguntas Frequentes

## What is Lifesaver-ai? / O que é o Lifesaver-ai?

An open-source project with safety skills for AI assistants, in English and Portuguese.

Um projeto open source com skills de segurança para assistentes de IA, em inglês e português.

## Is it free? / É gratuito?

Yes. The files in this repository are free to use under the Apache License 2.0.

Sim. Os ficheiros deste repositório são de uso livre ao abrigo da licença Apache 2.0.

## Does it replace a lawyer or a financial advisor? / Substitui um advogado ou um consultor financeiro?

No. For serious legal or financial decisions, talk to a qualified professional.

Não. Para decisões legais ou financeiras importantes, fala com um profissional qualificado.

## Can it be wrong? / Pode errar?

Yes. AI can make mistakes. Always double-check important information with an official source.

Sim. A IA pode cometer erros. Confirma sempre a informação importante com uma fonte oficial.

## Does it collect my data? / Recolhe os meus dados?

No. This repository only holds files and does not collect data. See `docs/privacy.md`.

Não. Este repositório só tem ficheiros e não recolhe dados. Ver `docs/privacy.md`.

## Does it work on every platform? / Funciona em todas as plataformas?

We do not know yet. Skills have not been tested everywhere. See `docs/installation.md`.

Ainda não sabemos. As skills não foram testadas em todo o lado. Ver `docs/installation.md`.

## How can I help? / Como posso ajudar?

Read `CONTRIBUTING.md`. You can report problems, test skills or improve the texts.

Lê o `CONTRIBUTING.md`. Podes reportar problemas, testar skills ou melhorar os textos.

## I found a security problem. What do I do? / Encontrei um problema de segurança. O que faço?

Do not open a public issue. Follow the steps in `SECURITY.md`.

Não abras uma issue pública. Segue os passos em `SECURITY.md`.
