# Installation / Instalação

Lifesaver-ai skills are text files written in Markdown. No programming is needed.

As skills do Lifesaver-ai são ficheiros de texto escritos em Markdown. Não é preciso programar.

## Important / Importante

Skills have not yet been tested on every platform. Do not assume that a SKILL.md file works the same way everywhere. Check the platform's own documentation.

As skills ainda não foram testadas em todas as plataformas. Não assumas que um ficheiro SKILL.md funciona da mesma forma em todo o lado. Consulta a documentação da própria plataforma.

## Simple method / Método simples

1. Open the `skills/` folder in this repository.
2. Choose a module, for example `skills/scam-detector/`.
3. Open the `SKILL.md` file and copy all its text.
4. Start a new conversation with your AI assistant and paste the text at the beginning, as instructions.
5. Then ask your question, for example: "Is this message a scam?"

1. Abre a pasta `skills/` neste repositório.
2. Escolhe um módulo, por exemplo `skills/scam-detector/`.
3. Abre o ficheiro `SKILL.md` e copia todo o texto.
4. Começa uma nova conversa com o teu assistente de IA e cola o texto no início, como instruções.
5. Depois faz a tua pergunta, por exemplo: "Esta mensagem é uma burla?"

## Safety reminders / Lembretes de segurança

- Never share passwords, PINs or card numbers with any AI.
- For serious legal or financial decisions, talk to a qualified professional.

- Nunca partilhes palavras-passe, PINs ou números de cartão com nenhuma IA.
- Para decisões legais ou financeiras importantes, fala com um profissional qualificado.
